# implied-vol-surface

`implied-vol-surface` is an early-stage Python workspace for learning and
building reusable crypto-options implied-volatility analytics. The current
implementation effort begins with Deribit BTC options.

## Status

The tracked code currently provides the minimal package foundation. Runnable
capabilities will be documented here as they are completed and verified.

## Development

Use the repository environment:

```bash
.venv/bin/python -m pip install -e '.[dev]'
```

## History

Earlier Bybit price-to-IV and grid-first visualization experiments remain
recorded in the `bybit-solved-iv-study` and `grid-visualization-study` Git tags
as part of the project's learning history.
